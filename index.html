Takror oraliqlari (kun)

Yangi so'z birinchi baholanganda shu oraliqlar ishlatiladi. Keyingi takrorlarda oraliq o'sib boradi, lekin bu qiymatlardan kam bo'lmaydi. Again ham shu oraliqni oladi. 0 — 10 daqiqadan keyin (shu o'tirishda).

GitHub sinxronlash

Progress sizning maxfiy (secret) GitHub Gist'ingizga avtomatik saqlanadi va boshqa qurilmada o'zi yuklanadi. Har qurilmada bir marta faqat gist huquqli token kiriting (GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → scope: gist). Token faqat shu brauzerda saqlanadi.
